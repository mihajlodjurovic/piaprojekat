===== POTREBNI ALATI =====
  Node.js >= 18
  MongoDB >= 6.0
  Angular CLI (`npm install -g @angular/cli@20`)


===== POKRETANJE =====
1. Pokrenuti MongoDB: mongod (ili sudo systemctl start mongod)
2. Backend:  cd backend && npm install && npm run seed && npm start
3. Frontend: cd frontend && npm install && ng serve
4. Otvoriti:  http://localhost:4200
